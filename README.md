# NAYVO — مصدر العمل الموحد

الفرع المعتمد للتطوير والنشر: **main** في adnan295/forsa.
التصميم المعتمد هو تصميم Claude المدمج: أبيض، أزرق، كحلي وذهبي، باسم NAYVO.
الفروع hostinger-vps-migration وclaude/app-modification-2ywc2r محفوظة للتاريخ فقط؛ لا تبنِ أو تنشر منها.

## أماكن التعديل
- app/ وcomponents/: واجهات Expo المشتركة للويب وiOS وAndroid.
- constants/colors.ts: الألوان والخطوط والمسافات المشتركة.
- server/: API؛ shared/schema.ts: مخطط قاعدة البيانات.
- app.json: النسخة ومعرّفات التطبيقات. لا تغيّر app.replit.forsa أو today.forsa.
- codemagic.yaml: بناء iOS من main؛ Dockerfile: بناء الويب والسيرفر من نفس الكود.
- /: واجهة المتجر المشتركة؛ /products: المنتجات؛ /admin: الإدارة المشتركة؛ /about: الصفحة التعريفية.

## طريقة العمل القادمة
ابدأ من أحدث main. نفّذ التعديل في فرع قصير العمر، راجعه واختبره ثم ادمجه في main.
كل بناء أو نشر يحدد commit SHA من main لتتبّع النسخة.
لا تنشئ نسخة منفصلة من واجهات الويب، ولا تعيد استخدام شاشة الحملات القديمة.
لا تعدّل server_dist أو web-build يدوياً؛ هذه مخرجات بناء.
